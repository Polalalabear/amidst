# 工作台 UI 改版規格 v1（PROPOSED）

- 日期：2026-11-08
- 作者：Claude Opus 5.5 / high
- 狀態：**IMPLEMENTED（以核可範例為準，見 §12）**；原 PROPOSED 內容保留，與 §12 不一致處以 §12 為準。實作要等 #445 整合分支完成，在它上面做。
- 依據：D126（兩個核心）、D129（先在 Mac 上跑起來）、使用者 2026-11-07～08 的 UI 要求、#383 的主頁面方向。

## 1. 目標與原則

1. **輔助，不追求即時**：使用者只需要知道目標大概在哪裡，原檔他會自己去調。檢索可以花時間，但畫面要一直讓人感覺系統在運作。
2. **視覺順暢**：播放、切鏡、捲動都不能卡頓。畫面上任何地方都不能出現超過 1 秒完全靜止的等待。
3. **追蹤分兩段**：第一次鎖定目標可以慢，用進度動畫帶過。鎖定之後，目標一出現在別台鏡頭就要立刻切過去（§6）。
4. **操作者畫面要簡單**：前台只留查找、追蹤和看結果。除錯、資料來源和參數都放到後台。
5. **證據狀態照舊區分**：OBSERVED、INFERRED、MISSING、UNKNOWN 照舊分清楚，身分維持 UNCONFIRMED。表現方式見 §7.4。

## 4. 主頁面（前台首頁）

由上而下分成六區：

1. **頂部列**：左邊是文字標誌「Amidst」；中間是「查找」「追蹤」「紀錄」三個入口；右邊是台灣時間時鐘（等寬字，每秒更新）和資料來源徽章。
2. **大字狀態區**：
   - 大標題用襯線字，例如「目前監看 7 台鏡頭」。
   - 副標用無襯線字，例如「最後一次偵測 14:03:12（台灣時間）· 場景 A4-1」。
3. **命令列**：仿 codex-reset 的 `❯`，提示文字是「我要找… 或 我要追蹤…」。
   - 點一下，或按 `/`、`Cmd+K`，就開啟指令面板（§4.1）。
   - 文字解析做好之前（#480），命令列只當入口，打開的是選單版的查找或追蹤卡片。
4. **狀態卡**，一列 3～4 張，每張左上角有小標籤：
   - 「鏡頭」：在線台數，以及每台的縮圖點陣。
   - 「目前追蹤」：目標類別、目前所在鏡頭、狀態（OBSERVED、INFERRED、LOST）。
   - 「最近事件」：最新一筆偵測或切鏡。
   - 「涵蓋區域」：R101～R104 等區域的覆蓋狀態，人工標註或未評估。
5. **時間軸直方圖**：橫軸是時間，以 10 秒為一格；縱軸是偵測數，依 person、物件分色。點一下就跳到那個時刻。
6. **事件流**：依時間排序，每列包含時間（等寬字）、鏡頭、事件，加上狀態標籤（OBSERVED、INFERRED、MISSING、UNKNOWN）。

### 4.1 指令面板

- 用 `/` 或 `Cmd+K` 開啟。內容是一個搜尋框加清單，例如「查找…」「追蹤…」「切換到單畫面」「切換到多畫面」「倍速 1x／1.5x／2x」「回主頁」。
- 鍵盤操作：↑↓ 移動、Enter 執行、Esc 關閉。

## 5. 兩個核心流程

### 5.1 case1 查找

1. **條件卡片**（從命令列或「查找」入口進來）：
   - 時間範圍：必填。用兩個時間選擇器，預設帶入目前事件的時間範圍。
   - 地點：可多選的膠囊列，每個區域一顆，例如 101 教室、走廊。
   - 特徵：下拉選單，選 COCO 類別，用中文顯示；選了人物時，可以再選顏色。
   - 地點和特徵至少要填一個。沒填時送出按鈕停用，下方顯示一行提示。
2. **檢索進度頁**，至少 3 個階段，依序亮起：
   - 讀取鏡頭（顯示 N／M 台）
   - 比對區域
   - 比對物件
   - 整理畫面
   - 每個階段都有自己的條狀進度。結果是陸續出來的：找到一個畫面，就先把縮圖淡入到結果區，不要等全部做完才一次顯示。
   - 背景可以加淡淡的「掃描線」或縮圖輪播動畫，讓畫面一直在動。
3. **結果牆**：
   - 縮圖網格，每張包含：鏡頭名稱、台灣時間、命中依據的標籤（地點覆蓋或偵測類別）。
   - 點縮圖會開啟大圖播放。大圖可以前後逐格，也有回到結果牆的按鈕。
   - 查無結果時顯示「這段時間沒有找到」，並提供「擴大時間範圍」的按鈕。

### 5.2 case2 追蹤

1. **條件卡片**：
   - 特徵必填。
   - 地點可選。
   - 時間可以空著，空著代表現在，下方顯示「從現在往回 60 秒」。
2. **首次鎖定**：可以慢。畫面顯示「在 7 台鏡頭中尋找目標…」，鏡頭縮圖逐一被掃描並亮起，搭配進度條。找到目標後，用約 300 ms 的轉場進入追蹤畫面。
3. **單畫面**（預設）：
   - 中央是大畫面，播放目前看得到目標的鏡頭，畫面上框出目標。
   - 下方是一條鏡頭時間條：用不同顏色的片段表示目標在哪台鏡頭的哪段時間，盲區用虛線片段。
   - 右側是俯視圖：實線是已觀測的路徑，虛線是預測。虛線本身就代表模擬，不另外加說明文字。
   - 目標離開畫面時，切到下一台看得到它的鏡頭（§6）。完全跟丟時，畫面顯示 LOST，並停在最後一次看到的畫面。
4. **多畫面**：所有找到目標的鏡頭排成網格。目前有目標的那格加上強調外框，其他格降低亮度。
5. 單畫面和多畫面用一個切換鈕互換，指令面板也能切換。
6. **倍速**：1x、1.5x、2x 放在播放列。實際跟不上設定值時，旁邊用小字顯示實際倍速（沿用 #408）。

## 6. 效能要求

| 項目 | 要求 | 做法 |
| --- | --- | --- |
| 鎖定後的切鏡延遲 | 從「目標出現在新鏡頭的那一格」到「新鏡頭畫面完整顯示」，P90 < 300 ms | 依 camera_graph 的 transitions，預先載入候選鏡頭在下一段時間的影格；用 #444 的代理影像（JPEG／WebP）；解碼放在背景執行 |
| 播放順暢度 | 1x 下，實際格率要達到來源 fps（5 fps）；1.5x、2x 可以自動降速，但不能跳格 | 每台鏡頭預先緩衝 2 秒影格；用 `requestAnimationFrame` 驅動；換用代理影像 |
| 靜止等待 | 任何等待都要有動畫或進度，靜止不可超過 1 秒 | 用骨架畫面、條狀進度、陸續出現的結果 |
| 轉場 | 150～300 ms 的 ease-out；切鏡用 120 ms 的淡入淡出 | CSS transition；尊重 `prefers-reduced-motion` |
| 首次鎖定 | 不限時，但要一直有進度回饋 | 同上 |

## 7. 視覺規格

### 7.1 色彩 token（深色為預設，另提供淺色）

| token | 深色 | 淺色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#141413` | `#faf9f5` | 頁面底色 |
| `--surface` | `#1f1e1d` | `#f5f4ed` | 卡片 |
| `--border` | `#30302e` | `#e8e6dc` | 細框線 |
| `--text` | `#faf9f5` | `#141413` | 主文字 |
| `--text-muted` | `#9c9a92` | `#73726c` | 次要文字 |
| `--accent` | `#d97757` | `#c6613f` | 強調色：目前鏡頭、主要按鈕 |
| `--observed` | `#7fb59a` | `#3f7d62` | 已觀測 |
| `--inferred` | `#6a9bcc` | `#3c6e9f` | 推測（一律配虛線） |
| `--missing` | `#5e5d59` | `#b0aea5` | 沒有畫面 |
| `--unknown` | 斜線紋理加 `--text-muted` | 同左 | 未知 |

### 7.2 字體

Anthropic 的專有字體不能用，改用外觀接近的開源字體（OFL），檔案放在 repo 裡，離線也能用：

- 大標題：Source Serif 4（襯線）。
- 內文和介面：Inter（無襯線）。
- 中文：系統的 PingFang TC，備援是 Noto Sans TC 和 Noto Serif TC 的子集。
- 數字、時間、鏡頭代碼：JetBrains Mono（等寬）。
- 字級：大標題 48～56 px，h2 28 px，內文 15 px，標籤 12 px（全大寫、加字距）。

### 7.3 元件

- 卡片：圓角 12 px，1 px 框線，不加陰影。
- 按鈕：膠囊形。主要按鈕是實心強調色，次要按鈕只有框線。
- 標籤：小型膠囊，配狀態色。
- 條狀進度：等寬字的 `█▓░` 式，或細條加光澤動畫。
- 指令面板：置中的浮層，背景加模糊。
- 浮動工具列：右下角，直排圖示按鈕。

### 7.4 證據狀態的表現

| 狀態 | 畫面 | 線條 |
| --- | --- | --- |
| OBSERVED | 實心框、`--observed` | 實線 |
| INFERRED | `--inferred` | **虛線**（就代表模擬，不加文字） |
| MISSING | 灰色占位，寫「沒有畫面」 | — |
| UNKNOWN | 斜線紋理 | — |
| 身分 | 目標旁的小標籤「身分未確認」 | — |

預測一律不用百分比或倒數。

## 8. 不做

- 手機版。只支援桌面寬度 1280～1920 px。
- 任何參考網站的 logo、品牌名、插圖或專有字體。
- 改動後端契約的語意。需要新欄位時，另外寫成 PROPOSED 契約增量。

## 12. 以使用者核可的設計範例為準的更新（2026-11-08，`claude/ui-redesign-v1`）

範例（設計畫布 Cover／Search／Track／Main／Settings）與上文不一致時以範例為準。實作差異如下：

| 項目 | 本規格原寫 | 實作（依範例） |
| --- | --- | --- |
| 前台入口 | 主頁面六區（大字狀態、命令列、狀態卡、直方圖、事件流） | 封面（大標題 Amidst，進場動畫全部在 0.6 秒內結束）→「進入系統」→ case1 查找／case2 追蹤／case3 查看三選一，過渡 0.25 秒。狀態卡、直方圖、事件流移到後台「概況」 |
| 指令面板 `/`、`Cmd+K` | 有（§4.1） | 本版不做；入口是懸浮查詢窗（左上漢堡鈕開關，Esc 收起） |
| case1 | 條件卡片＋進度頁＋縮圖網格 | 可收合懸浮查詢窗；結果牆兩欄、畫面高 340 px；進度為四段分段進度條，並在頁首顯示進度徽章；點縮圖開大圖，可前後切換 |
| case2 | 時間可空白，顯示「從現在往回 60 秒」 | 時間只有「開始」一欄，空白＝現在；不顯示「往回 60 秒」；有開始時間時，結束取來源時鐘的結尾 |
| case2 畫面 | 右側俯視圖 | 鏡頭時間軸（實線＝OBSERVED、虛線＝盲區 INFERRED）＋樓層俯視圖＋追蹤紀錄；俯視圖不加圖例文字，實線／虛線自己說明。鏡頭位置資料沒有時，俯視圖寫 UNKNOWN，不畫假的平面圖 |
| case3 | 無 | 接現有事件回放：監控牆、Q1、B-05b，A4-1／B4-1 與 B-05a 以內嵌方式（需啟動腳本帶埠） |
| 後台 | 事件選擇、資料來源、provider 等 | 左側選單：概況／設定／鏡頭播放／紀錄。概況＝狀態卡、偵測數據卡、各鏡頭偵測數、時間軸、事件流；設定值只存在瀏覽器（localStorage） |
| 數字 | 未規定 | 沒有實測來源的數字顯示「尚未量測」或 UNKNOWN，不放範例值。偵測速度、切換 P90、Agent 回應目前無來源，一律「尚未量測」；首次鎖定、查找耗時是本機量測；缺幀率取自來源宣告的取樣範圍；盲區占比取自追蹤回應 |
| 字體 | 檔案放 repo | 本版用本機字體堆疊（Source Serif 4／Inter／Noto TC／JetBrains Mono，已安裝才會用，否則退回系統字體），不連外。把 OFL 字型檔放進 repo 是後續工作 |
| 資料來源徽章 | 右上角半透明 | 同，標籤為 SYNTHETIC／REPLAY／LIVE，滑過去顯示說明；紅色大橫幅在前台移除 |
| 舊畫面 | 取代 | `?ui=legacy` 仍可開舊工作台；新前台只經 `ctx.legacy`（app.mjs 的 LEGACY BRIDGE）接舊 DOM，之後清理只需刪那一塊與 index.html 的引擎 DOM |
