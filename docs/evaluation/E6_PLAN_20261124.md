## R-N 規格（和 AO 對齊；依 main `aopen/decider.py`、`neutral.py`、`tracker.py`）

| 項目 | 規定 |
| --- | --- |
| 起始 | 同一個種子 tick（B1 第一次 ACQUIRE）；從種子取初始估計位置，第一次決策為 FIRST |
| 提問時機 | POLL 2.0 s；**LOST_EARLY**：R-N 自己的中性追蹤器失聯且距上次 ≥ 1.0 s；同一個呼叫上限 ⌈秒數 ÷ 2 × 1.5⌉ |
| 候選 | 和 AO 相同的凍結偵測；規則只對其中 red、且投影得出地面點的框做距離閘門 |
| 狀態 | **讀 R-N 自己的中性追蹤狀態**（估計位置、失聯時間），不讀 B1 的追蹤狀態。失聯後中性追蹤器會清掉位置，所以 R-N 另存「最後已知位置與時間」並寫進紀錄；AO 的請求在失聯後沒有這項，是已知差異 |
| 生效 | 提問的下一個 tick，框用提問時的框；NeutralTracker 的參數不動（IoU 0.3、滑行 2 tick、遮擋 10 tick） |
| 沒有合格候選 | 主要版本＝UNCERTAIN（不改目標）；另跑 NOT_VISIBLE（清除）當敏感度。**兩個版本在執行前寫定** |
| 差異 | 規則不能畫框（OWN_BOX），AO 可以；AO 的請求帶著 B1 的追蹤狀態當資訊，R-N 沒有。報告列出，並報 OWN_BOX 佔比 |

規則追蹤器 `Tracker.update` 是 5 Hz 有狀態的演算法，沒有「只答一次」的函式，所以 R-N 需要新的轉接層（重用同一個距離閘門與顏色條件），**不能直接搬 B1 已選好的結果**；搬用只能標成「重播診斷」。R-N 改變了規則原本的頻率，結論只能寫「在中性追蹤器底座上」，不能寫成「規則（B1）較差／較好」。舊 16 段上的 R-N 只是事後描述。

## 統計與獨立性（預登要寫）

- 12 段是為了增加**獨立情境**，不保證統計能力。雙尾符號檢定（獨立、無平手）：8/8 的 p = 0.0078，10/12 的 p = 0.0386；不能直接套到 bootstrap 或決策點檢定。
- 開頭不同不等於獨立。#718 要列每段的路線、人物時序、相似人物來源、劇本家族，同家族的段合併成一個統計單位，並寫有效獨立單位數。
- **主要假設兩個**，Holm 校正：**P1 去錨定對原 AO**（改良效果）；**P2 開發資料上選定並凍結的 Agent 組對 B1**（核心目的：是否優於現有規則系統）。R-N 是機制分析與次要比較，勝過 R-N 不能寫成優於現有規則。
- **判定用連言，避免只靠少顯示目標降低錯人秒**：兩個主要假設都沿用 E3／E5 的 `verdict_h1`（錯人秒差區間整個 < 0、跟對率差區間下界 > −0.05、McNemar p < 0.05，三項都要），再加 **盲區誤鎖秒差區間上界 ≤ 預先寫死的容許值**。容許值由 #718 在看任何新資料前寫定，並附理由；沿用 E5 H8b 的「區間整個 < 0」是較嚴的次要判定。失聯／不顯示秒另報。
- **Holm 怎麼套（#718 定稿，這裡是預設）**：E3／E5 的 `verdict_h1` 與其判定**保持不變**；E6 另寫新的判定函式。每個主要假設由四個單尾元件組成：錯人秒差 < 0、跟對率差 > −0.05、決策點正確率較高、盲區誤鎖秒差 ≤ 容許值。四個都要成立（交集－聯集檢定），所以該假設的 p = **四個元件 p 的最大值**，不需再除。再把 P1、P2 兩個 p 做 Holm：整體單尾 α = 0.025，較小的 p 要 ≤ 0.0125，較大的 p 要 ≤ 0.025；第一步沒過，第二步也不判成立。區間同步用對應的校正水準，**不能拿原始 95% 區間或 `p < 0.05` 宣稱已校正**。元件檢定一律以劇本家族（獨立單位）做符號翻轉或群集重抽，不把同段的決策點當獨立；McNemar 只另報。反方向（Agent 較差）用同一套校正判「不成立」，其餘「無法判斷」。實際檢定、抽樣數、種子由 #718 寫死。
- **資料嚴格分離**：3 段診斷資料**不得出現在正式 12 段內**，也不得和正式段同一劇本家族。預設從舊 16 段選（AO、B1 已有紀錄，省費用），正式 12 段不得重用舊 16 段的劇本家族；用 SHA 清單加自動檢查證明不相交。**40 個決策點是最低門檻，不是樣本獨立的證明**，同劇本內的相關性由上面的家族單位處理。
- **樣本門檻**：`verdict_h1` 少於 40 個決策點或 8 段就算探索性。12 段劇本要有 **≥ 40 個決策點**（錄製前由劇本定）；同家族合併後的有效獨立單位也要 ≥ 8，否則標探索性，不降門檻。
- **B1 在新劇本上照跑**（同一份凍結偵測，確定性程式，零模型費用）。B1 與 R-N 都不得在看到新資料結果後改參數。
- 其餘比較為次要。要寫可偵測的效果大小；區間跨 0 就寫「無法判斷」。P2 不成立時照實寫「改良後仍未證實優於現有規則」。
- 開發資料 3 段太少，選組很不穩；選擇規則要預先寫死（含平手時取較簡單的組），不能解讀成勝負。
