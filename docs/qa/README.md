# 使用者問答紀錄（導覽索引）

這個資料夾收錄使用者（專案負責人）至今在各協調者 session 與既有文件中問過的問題，以及**當時**的回答。本頁只列問題摘要，**不含答案**；點「檔案連結」進入對應問答。

## 怎麼讀

- 每題有固定編號 `YYYYMMDD-NN`（依提問時間排序），可用連結直接跳到該題。
- 回答照當時內容摘錄，不補入當時沒有的結論；每題的「後續」欄註明是否被後來的決定取代。數字與進度是當時的快照，即時狀態以 issue／PR 為準。
- 日期以 Asia/Taipei 計（協調者當時以台北時間回報；使用者實際時區未明示，屬推定）。每題內另附 UTC 時間。
- 規格與決策的依據仍是各契約與 issue／PR；決策編號 D1–D25 在 [#25](https://github.com/Polalalabear/amidst/issues/25)、[#26](https://github.com/Polalalabear/amidst/issues/26)，D26–D47 在 #65、#66、#67、#68、#69、#72。
- 受控場景人物位置估計（遮擋、上半身區間、3D 人物來源）另有 A 包整理的正式說明：[CONTROLLED_SCENE_ESTIMATION_QA_20261018.md](https://github.com/Polalalabear/amidst/blob/36b7781538e14149f50f5bbb50284a0d6e314d0e/docs/agents/CONTROLLED_SCENE_ESTIMATION_QA_20261018.md)（PR #65，`claude/controlled-scene-a` @ `36b7781`；合併進整合分支前，此連結指向該分支的固定 commit）。本資料夾的 [20261018 估計問答](20261018_受控場景估計與遮擋.md)則保留使用者提問與當時的回答原文。
