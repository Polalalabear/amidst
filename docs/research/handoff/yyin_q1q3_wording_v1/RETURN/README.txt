回件放這裡

指定回件檔：
  RETURN/題集_yyin_YYYY-MM-DD.csv
  （YYYY-MM-DD 換成你交件那天，例如 題集_yyin_2026-11-10.csv）

做法：
  1. 打開上一層的 題集模板.csv
  2. 填好後「另存新檔」，格式選 CSV UTF-8
  3. 檔名改成上面的名字，存到這個 RETURN 資料夾
  4. 重新打開一次，確認中文、欄名、秒數沒有跑掉

沒做完也可以交：檔名改成 題集_yyin_YYYY-MM-DD_INCOMPLETE.csv，
並在交件訊息寫哪些題族沒做完、為什麼。

不要放進這裡：影片、截圖、劇本或任何系統輸出。

這份題集是 v1，evaluation_eligible=false；使用者核准前不算正式評估資料。
