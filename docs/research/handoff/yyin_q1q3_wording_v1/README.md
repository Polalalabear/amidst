# Q1／Q3 查詢用字題集包 v1（給 yyin）

- 版本：`v1`（2026-11-03；修訂 1：三種事件定案、附影片）
- 狀態：**`evaluation_eligible=false`**。使用者核准之前，這份題集一律不算正式評估資料。
- 依據：#93 D121-C，研究企劃 `docs/research/MODEL_EXPERIMENT_PLAN_20261102.md` §5.10（#397）。
- 這個包有文字、表格，和 `videos/` 資料夾裡每台鏡頭一支的影片（共 11 支）。影片只是畫面加左上角的「場景／鏡頭／秒數」標示，沒有框、軌跡或其他資訊。

## 這份工作內容

研究要比較「系統聽不聽得懂不同說法」。同一件事，有人會說「經過某轉角」，有人會說「經過外面」，也有人用時間說「開始後大約 20 秒」。我們想知道系統（規則版和 LLM 版）會不會因為說法不同就找錯。

請你看影像，針對**三種事件**各出一組查詢題：

1. 三種事件已經定案，見下一節「三種事件類別」。`E1`、`E2`、`E3` 就是那三類，不用再問使用者。
2. 每一組出 **10 個題族**。一個題族就是「同一件事」：同一個場景、同一段時間、要找的同一個人或物。
3. 每個題族至少寫 **3 種說法**，各一句：

| 說法類型 | 意思 | 句型示範（不要照抄） |
| --- | --- | --- |
| `P` 精確地點詞 | 講出具體的轉角、門口、走廊、鏡頭位置 | 「有人經過某轉角的時候」 |
| `V` 模糊空間詞 | 只講大概方位，例如外面、裡面、那邊 | 「有人經過外面的時候」 |
| `T` 時間詞 | 用時刻或相對時間指出這件事 | 「開始後大約 20 秒有人經過」 |
| `C` 組合（選填） | 地點詞加時間詞 | 「開始後 20 秒左右，有人經過某轉角」 |

4. 每一句都要依你在影像裡看到的，填上**預期答案**：這件事發生的時間窗（從影片開始算的秒數）、哪幾台鏡頭拍得到、預期結果。

## 三種事件類別

三類只看「人或車在畫面裡做了什麼」，不涉及身分、路線規劃或碰撞。**每類可以跨場景出題**（A4-1、B4-1、P1 都可以），同一題族只用一個場景、一個時間窗。

### 怎麼區分三類

| 類別 | 事件 | 一句話 |
| --- | --- | --- |
| `E1` | 經過某處 | 人或車從某個位置的一邊走到另一邊，**沒有停下，也沒有進出建築**。 |
| `E2` | 進出室內外 | 人或車**穿過門口**，從外面到裡面，或從裡面到外面。 |
| `E3` | 停留或折返 | 人或車**停下一段時間**，或**走到一半轉身往回走**。 |

容易搞混時的判斷原則（依序用）：

1. 有沒有穿過門口、進出室內外？有就是 `E2`，就算他同時也「經過」門口。
2. 沒有進出，但有停下超過約 2 秒，或有轉身往回走？是 `E3`。
3. 都不是，只是連續走過去？是 `E1`。
4. 一個畫面同時符合兩類（例如走進門又在門內停下）：出題時只選你這句話要講的那一個動作，並把時間窗限在那個動作；在備註寫「也符合 E2」之類。
5. 還是分不清，就在「看不清或不確定」填「是」，備註寫原因。不要硬湊。

### E1 經過某處

- **定義**：在某個位置（轉角、走廊、門口前、路口、鏡頭前方）連續走過或駛過，沒有停下，也沒有進出建築。
- **範例句**（同一題族、同一件事）：
  - `P`：「有沒有人經過走廊的轉角？」
  - `V`：「有沒有人經過外面？」
  - `T`：「開始後大約 20 秒，有沒有人走過去？」
- **關鍵字表**

| 類型 | 關鍵字（只是範例，請依影像用你自己的話） |
| --- | --- |
| 精確地點詞 | 轉角、走廊、走廊轉角、門口、入口前、路口、分岔、某號門前、某台鏡頭前（用鏡頭代號） |
| 模糊空間詞 | 外面、裡面、那邊、這邊、前面、後面、旁邊、附近、遠處 |
| 動作詞 | 經過、走過、路過、穿過、駛過、通過 |

### E2 進出室內外

- **定義**：穿過門口，從外面進到裡面，或從裡面出到外面。以影像裡看得到穿過門的動作為準。
- **範例句**：
  - `P`：「有沒有人從入口走進室內？」
  - `V`：「有沒有人從外面進來？」
  - `T`：「開始後大約 15 秒，有沒有人走進去？」
- **關鍵字表**

| 類型 | 關鍵字 |
| --- | --- |
| 精確地點詞 | 入口、門口、大門、某號門、出口、玄關 |
| 模糊空間詞 | 外面、裡面、室內、室外、屋裡、屋外、進去、出去、那邊 |
| 動作詞 | 進來、進去、走進、走出、出來、離開、進入 |

### E3 停留或折返

- **定義**：人或車在某處停下（站著、坐著、等待），或走到一半轉身往回走。停下要超過約 2 秒才算。
- **範例句**：
  - `P`：「有沒有人在走廊轉角停下來？」
  - `V`：「有沒有人在外面逗留？」
  - `T`：「開始後大約 30 秒，有沒有人停在那裡？」
- **關鍵字表**

| 類型 | 關鍵字 |
| --- | --- |
| 精確地點詞 | 轉角、走廊、門口、入口前、路邊、停車位、某台鏡頭前 |
| 模糊空間詞 | 外面、裡面、那邊、旁邊、附近、原地、同一個地方 |
| 動作詞 | 停下、停留、逗留、站著、等待、折返、回頭、走回去、掉頭 |

### 出題時的提醒

- 關鍵字只是參考。**地點詞要對得上你在影像裡看到的位置**；影片裡沒有「轉角」就不要寫轉角。鏡頭代號只是名字，不要依名字猜畫面。
- `P` 要具體到別人看了影像能指出是哪裡；`V` 故意模糊，一般人聽了可能不確定指哪裡，這時預期結果可以填「反問」。
- `T` 的秒數用影片左上角標示的秒數，不要用別的時鐘。
- 顏色只用在人身上，不是每題都要。

## 影片

- 位置：`videos/`，每台鏡頭一支 MP4，檔名 `場景_鏡頭.mp4`（例如 `A4-1_CAM_ENTRY.mp4`、`P1_A.mp4`）。清單和長度見 `VIDEOS.json`。
- 左上角的「場景／鏡頭／秒數」是從該影片開始算的秒數（小數兩位）。時間窗的秒數就填這個。
- 同一場景的不同鏡頭**同一個秒數代表同一時刻**。
- A4-1、B4-1 是每秒 5 張，P1 是每秒 20 張；影片已保持原 fps，所以 A4-1／B4-1 看起來比較不流暢，這是正常的。
- 影片只是檢視用，不要重新編碼、剪輯或對外分享。

可以出題的場景和鏡頭（只用這些代號；代號只是名字，不要依名字猜畫面內容）：

| 場景 | 片長 | 鏡頭 |
| --- | --- | --- |
| A4-1 | 50 秒 | CAM_ENTRY、CAM_EXT_CAR、CAM_EXT_CLEAR、CAM_W1 |
| B4-1 | 42 秒 | CAM_BRANCH、CAM_R101_IN、CAM_W1、CAM_W2、CAM_WIDE |
| P1 | 8 秒 | A、B |

P1 很短（8 秒），可以用也可以不用；每個題族只能用一個場景。

規則：

- **答案只能依你在影像裡看到的**。不要看、也不要問劇本、人物設定、路線、GT 或系統的輸出；不要從檔名、相鄰劇情或系統畫的框反推答案。
- 看不清楚（太小、被擋住、太暗、出畫面）就在「看不清或不確定」填「是」，備註寫原因，不要猜。
- 「模糊說法」的正確答案有可能就是「系統該反問」。你覺得這句話一般人聽了也不知道指哪裡，就填「反問」；覺得聽得懂，就照影像填。
- 只出找人、找車或找相機的題目。不要出問身分（是不是同一個人、叫什麼名字）、問路線或問「會不會撞到」的題目，系統不支援。
- 顏色只用在人身上（例如紅衣、藍衣）。
- 句子裡不要放真實人名或個資。

## 要提交的項目

1. **`RETURN/題集_yyin_YYYY-MM-DD.csv`**（日期填你交件那天）。從 `題集模板.csv` 另存成 **CSV UTF-8**。三組共 90 列預先編好號（`事件類別` 欄已填好），全部保留、不要刪；要加 `C` 類就在同題族後面加一列，編號寫成 `E1-F01-C`。
2. 整個資料夾，或壓成 ZIP。
3. 一段交件訊息：三組各完成幾個題族、哪些題族沒做完和原因、哪些句子你自己也不確定。

## 操作步驟

1. 把整個資料夾解壓縮，先讀完這份 README 和 `RETURN/README.txt`。
2. 確認 `videos/` 的影片都能播放。
3. 用 Excel、Numbers 或 Google 試算表打開 `題集模板.csv`。
4. 看影像，挑一件事當題族（例如某個人走過某處的那一段），記下它在第幾秒開始、第幾秒結束、哪幾台鏡頭拍得到。
5. 為這個題族寫 `P`、`V`、`T` 三句（`C` 選填）。同一題族的三句，場景、時間窗、要找的東西都一樣，只有說法不同。
6. 每一句填完下面的欄位：

| 欄位 | 怎麼填 |
| --- | --- |
| 編號、事件組、事件類別、題族編號、說法類型 | 已經編好，不要改 |
| 使用者會說的話 | 一句完整、自然的中文 |
| 想找什麼 | 人／車／相機（問「哪些鏡頭拍到…」填相機） |
| 顏色 | 有講顏色才填，否則留空 |
| 場景 | A4-1／B4-1／P1（同一題族只用一個場景；不同題族可以用不同場景） |
| 時間窗開始、結束（秒） | 從影片開始算，例如 `18.0`、`23.4`；不要改成日期格式 |
| 預期鏡頭 | 上表的代號，多台用 `;` 分開；不知道就留空並在備註說明 |
| 系統該反問嗎 | 是／否 |
| 預期結果 | 找得到／找不到／不支援／超出時間／反問，五選一 |
| 看不清或不確定 | 是／否 |
| 備註 | 你用的地點說法對應畫面哪裡、為什麼不確定等 |

7. 存檔時選 **CSV UTF-8**，檔名改成 `題集_yyin_YYYY-MM-DD.csv`，放進 `RETURN/`。存完重新打開一次，確認中文、欄名、秒數都沒有跑掉。
8. 把整個資料夾（或 ZIP）和交件訊息交給使用者。

## 不要改

- `README.md`、`RETURN/README.txt`、`題集模板.csv`、`MANIFEST.json`、`videos/`、`VIDEOS.json` 本身不要改；只在另存的回件檔裡填答案。
- 欄名和預先編好的編號、事件類別不要改。
- 這份題集的狀態是 `evaluation_eligible=false`，你交回之後也不會自動變成正式資料，要使用者核准。
