# Q1／Q3 查詢用字題集包 v1（給 yyin）

- 版本：`v1`（2026-11-03）
- 狀態：**`evaluation_eligible=false`**。使用者核准之前，這份題集一律不算正式評估資料。
- 依據：#93 D121-C，研究企劃 `docs/research/MODEL_EXPERIMENT_PLAN_20261102.md` §5.10（#397）。
- 這個包只有文字和表格，**沒有影像**。影像由使用者另外提供給你。

## 這份工作內容

研究要比較「系統聽不聽得懂不同說法」。同一件事，有人會說「經過某轉角」，有人會說「經過外面」，也有人用時間說「開始後大約 20 秒」。我們想知道系統（規則版和 LLM 版）會不會因為說法不同就找錯。

請你看影像，針對**三種事件**各出一組查詢題：

1. 三種事件是哪三種，使用者轉交這個包時會一起告訴你，分別填在 `E1`、`E2`、`E3`。還沒收到說明就先不要開始，請直接問使用者。
2. 每一組出 **10 個題族**。一個題族就是「同一件事」：同一個場景、同一段時間、要找的同一個人或物。
3. 每個題族至少寫 **3 種說法**，各一句：

| 說法類型 | 意思 | 句型示範（不要照抄） |
| --- | --- | --- |
| `P` 精確地點詞 | 講出具體的轉角、門口、走廊、鏡頭位置 | 「有人經過某轉角的時候」 |
| `V` 模糊空間詞 | 只講大概方位，例如外面、裡面、那邊 | 「有人經過外面的時候」 |
| `T` 時間詞 | 用時刻或相對時間指出這件事 | 「開始後大約 20 秒有人經過」 |
| `C` 組合（選填） | 地點詞加時間詞 | 「開始後 20 秒左右，有人經過某轉角」 |

4. 每一句都要依你在影像裡看到的，填上**預期答案**：這件事發生的時間窗（從影片開始算的秒數）、哪幾台鏡頭拍得到、預期結果。

可以出題的場景和鏡頭（只用這些代號；代號只是名字，不要依名字猜畫面內容）：

| 場景 | 片長 | 鏡頭 |
| --- | --- | --- |
| A4-1 | 50 秒 | CAM_ENTRY、CAM_EXT_CAR、CAM_EXT_CLEAR、CAM_W1 |
| B4-1 | 42 秒 | CAM_BRANCH、CAM_R101_IN、CAM_W1、CAM_W2、CAM_WIDE |
| P1 | 8 秒 | A、B |

P1 要不要用，看使用者對「三種事件」的說明。

規則：

- **答案只能依你在影像裡看到的**。不要看、也不要問劇本、人物設定、路線、GT 或系統的輸出；不要從檔名、相鄰劇情或系統畫的框反推答案。
- 看不清楚（太小、被擋住、太暗、出畫面）就在「看不清或不確定」填「是」，備註寫原因，不要猜。
- 「模糊說法」的正確答案有可能就是「系統該反問」。你覺得這句話一般人聽了也不知道指哪裡，就填「反問」；覺得聽得懂，就照影像填。
- 只出找人、找車或找相機的題目。不要出問身分（是不是同一個人、叫什麼名字）、問路線或問「會不會撞到」的題目，系統不支援。
- 顏色只用在人身上（例如紅衣、藍衣）。
- 句子裡不要放真實人名或個資。

## 要提交的項目

1. **`RETURN/題集_yyin_YYYY-MM-DD.csv`**（日期填你交件那天）。從 `題集模板.csv` 另存成 **CSV UTF-8**。三組共 90 列預先編好號，全部保留、不要刪；要加 `C` 類就在同題族後面加一列，編號寫成 `E1-F01-C`。
2. 整個資料夾，或壓成 ZIP。
3. 一段交件訊息：三組各完成幾個題族、哪些題族沒做完和原因、哪些句子你自己也不確定。

## 操作步驟

1. 把整個資料夾解壓縮，先讀完這份 README 和 `RETURN/README.txt`。
2. 確認使用者已經告訴你 `E1`、`E2`、`E3` 是哪三種事件，也已經拿到影像。
3. 用 Excel、Numbers 或 Google 試算表打開 `題集模板.csv`。
4. 看影像，挑一件事當題族（例如某個人走過某處的那一段），記下它在第幾秒開始、第幾秒結束、哪幾台鏡頭拍得到。
5. 為這個題族寫 `P`、`V`、`T` 三句（`C` 選填）。同一題族的三句，場景、時間窗、要找的東西都一樣，只有說法不同。
6. 每一句填完下面的欄位：

| 欄位 | 怎麼填 |
| --- | --- |
| 編號、事件組、題族編號、說法類型 | 已經編好，不要改 |
| 使用者會說的話 | 一句完整、自然的中文 |
| 想找什麼 | 人／車／相機（問「哪些鏡頭拍到…」填相機） |
| 顏色 | 有講顏色才填，否則留空 |
| 場景 | A4-1／B4-1／P1 |
| 時間窗開始、結束（秒） | 從影片開始算，例如 `18.0`、`23.4`；不要改成日期格式 |
| 預期鏡頭 | 上表的代號，多台用 `;` 分開；不知道就留空並在備註說明 |
| 系統該反問嗎 | 是／否 |
| 預期結果 | 找得到／找不到／不支援／超出時間／反問，五選一 |
| 看不清或不確定 | 是／否 |
| 備註 | 你用的地點說法對應畫面哪裡、為什麼不確定等 |

7. 存檔時選 **CSV UTF-8**，檔名改成 `題集_yyin_YYYY-MM-DD.csv`，放進 `RETURN/`。存完重新打開一次，確認中文、欄名、秒數都沒有跑掉。
8. 把整個資料夾（或 ZIP）和交件訊息交給使用者。

## 不要改

- `README.md`、`RETURN/README.txt`、`題集模板.csv`、`MANIFEST.json` 本身不要改；只在另存的回件檔裡填答案。
- 欄名和預先編好的編號不要改。
- 這份題集的狀態是 `evaluation_eligible=false`，你交回之後也不會自動變成正式資料，要使用者核准。
