### 2.1 補跑：`SELECTED_GROUP_MISSING`（狀態 3）

Colab 依標籤表暫定選組，Mac 用 GT 分群重選。兩者不同時，Mac 選出的（模型, 級）沒有第二部分結果，評分會停下（設計 G6）。結果 md 頂端會寫出缺的組和要貼的那一行。notebook 和 pin `62981f08` 都不用改，步驟：

1. 在 Colab 開同一本 notebook，第 1 格改 `RUN_MODELS = ["<模型>"]`，`RUN_PART2 = True` 不變。
2. 在第 7 格和第 8 格之間插一格，貼上（換成 md 列出的模型與級）：
   ```python
   SELECTION["per_model"]["<模型>"] = {"level": "<級>"}; SELECTION["selected"] = {"model": "<模型>", "level": "<級>"}
   ```
3. Run All。已完成的組會從 Drive 的 checkpoint 續跑，只會新跑那個模型在該級的 ZERO_LATENCY 和 MEASURED 兩組，以及很快的 B1 重現閘門。
4. 下載新的 `e8-run-<日期>.zip`（內含所有 checkpoint），重跑 §2 的指令。這次應以狀態 0 結束。
