## Colab L4 操作（使用者做）

1. Colab 開新筆記本 → 執行階段 → 變更執行階段類型 → **L4 GPU**。
2. 左側檔案面板上傳 `/Users/polalabear/amidst/local/data/wp5-packs-20261115/wp5-pack_colab_l4_20261115.zip`。
3. 新程式格執行：
   ```
   !unzip -q wp5-pack_colab_l4_20261115.zip && mv wp5-pack_colab_l4_20261115/* .
   ```
4. 在左側面板開 `notebooks/agent_decision/wp5_colab_l4.ipynb`，把它的各格貼進筆記本（或把這個 .ipynb 下載後用「檔案 → 上傳筆記本」開，再 cwd 設在包根目錄）。由上而下逐格執行：步驟 0 驗包（`VALID`）→ 1 確認 L4（不是 L4 會停）→ 2 設定（`SET="pilot"`、`OLLAMA_VERSION="AUTO_LATEST"` 會取當日最新版並寫進 `ENV.json`、`SKIP_TYPES="DP4"`）→ 3 安裝 Ollama（一次只載一個模型）→ 4 pull 兩個 q4_K_M 模型並驗 digest → 5 dry-run（0 次呼叫）→ 6 逐模型暖機＋跑題組＋卸載 → 7 打包。
5. 跑完會產生 `RETURN/wp5_pilot_colab_l4.zip` 並自動下載；沒下載就從檔案面板下載。
6. 把它放到 Mac 的 `local/evidence/wp5/pilot/`，執行 `shasum -a 256 <檔>`，把 SHA-256 貼回給協調者。

指定回傳檔：`RETURN/wp5_<set>_colab_l4.zip`（內含兩個模型資料夾的 `calls.jsonl`／`summary.json`／`summary.md`／`MANIFEST.json`，以及 `ENV.json`）。

## Windows 操作（外包機）

1. 解壓 `wp5-pack_windows_20261115.zip`，在資料夾內（Python 3.12 以上）：`python run.py --set pilot`（dry-run，0 次呼叫，不需要 Ollama，應看到 `VALID` 與 `DRY RUN only`）。
2. 裝好 Ollama for Windows 後：`python run.py --set pilot --live`（pull 兩個模型、寫 digest、一次跑一個、`--arm windows`）。
3. 指定回傳檔：`RETURN/wp5_<set>_windows.zip`。`ENV.json` 的 `latency_reportable` 是 `false`：這台沒有 L4，**延遲不可當正式結果**，只看流程與逾時／備援行為。
4. 放進 Mac 的 `local/evidence/wp5/pilot/`，記下 SHA-256。
