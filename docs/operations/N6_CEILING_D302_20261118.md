# N6 天花板材質對照（#593）

載入 N6 GLB 時，`CEILING_STATIC_LIVE` 使用自己的 unlit 材質副本。Shader 將貼圖的 linear RGB
與暖灰底色混合，保留 22% 貼圖訊號，壓低亮斑並減少烘焙色差形成的接縫。牆、地板和其他物件
仍從原材質取樣。天花板與牆的幾何交界、牆上的烘焙陰影，以及 operator 原本隱藏天花板的行為都可在對照中看到。

前後畫面使用同一份 A4-1 腳本，固定 **12.0 s**、同一 operator 視角與八個校正鏡頭。
比較腳本只在測試 HTTP server 上凍結 operator 的動畫 clock。system 以 grid 模式接收真實的
虛擬相機 JPEG，推論由 fixture 回傳空觀測。兩組都完成實際頁面渲染，頁面錯誤及 protocol 違規均為 0。
GLB、人物、校正、scenario 和 geometry 的前後 SHA 相同。operator canvas 的 920×720 RGB
前後像素一致；三個室內相機的天花板取樣如下，亮度單位為 8-bit 灰階。

| 鏡頭與區域（左、上、右、下 px） | 平均亮度前 → 後 | 標準差前 → 後 | 峰值前 → 後 |
| --- | ---: | ---: | ---: |
| CAM_WIDE (225, 5, 435, 21) | 137.72 → 121.25 | 5.18 → 1.35 | 145 → 123 |
| CAM_W2 (260, 8, 375, 25) | 121.48 → 117.26 | 1.86 → 0.54 | 125 → 119 |
| CAM_W1 (200, 8, 310, 23) | 112.41 → 115.34 | 3.77 → 0.87 | 122 → 118 |

CAM_W1 原取樣較暗，混色填高了暗部，峰值仍下降。這次驗收涵蓋畫面亮度與烘焙色差。
改後真實偵測品質尚未量測。
