`E3_PYTHON`, `RUNTIME_DEPS`, `LIVE_ASSETS`, `CAMERA_CATALOG` and `MODEL_ROOT` from your local setup;
no source assets are copied or overwritten. Install the frontend lockfile with
`npm ci --ignore-scripts` in `frontend/live-mode`. Use a new output directory
when rebuilding; keep the frozen corpus for F4.
